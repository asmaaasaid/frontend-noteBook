#  Frontend Notebook

أهلًا بيك في **Frontend Notebook**!

الريبو ده عبارة عن مجموعة من الملخصات والملاحظات في مجال **Frontend Development**، جمعتها ونظمتها هنا عشان تكون متاحة لكل شخص مهتم بتعلم Frontend أو حابب يراجع معلوماته ويرجع لها وقت ما يحتاج.

##  فكرة المشروع

الفكرة ببساطة إننا نشارك المعرفة ونخلي الوصول للمعلومات أسهل.

سواء كنت لسه بتبدأ تتعلم Frontend أو عندك خلفية وعاوز تراجع معلوماتك، هتلاقي هنا ملخصات تساعدك في رحلة التعلم.

##  المحتوى

الريبو بيضم ملخصات بصيغة PDF لمجموعة من موضوعات Frontend، منها:

- HTML
- CSS
- JavaScript
- Bootstrap
- Tailwind CSS
- React
- Angular
- Git & GitHub

المحتوى بيتضاف ويتحدث باستمرار، ومع الوقت هتلاقي مواضيع وملخصات أكتر.

##  تقدر تستفيد من المشروع إزاي؟

- اختار الموضوع اللي حابب تتعلمه أو تراجعه.
- افتح الـ PDF واقرأ الملخص مباشرة.
- حمل الملفات واحتفظ بيها عشان ترجع لها وقت ما تحتاج.

##  شارك وساهم

لو عندك اقتراحات أو أفكار لتطوير المشروع، أو حابب تشارك مصادر تعليمية مفيدة، يسعدني جدًا مشاركتك.
